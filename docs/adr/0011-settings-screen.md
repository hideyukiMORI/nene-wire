# ADR 0011 — 設定画面は帯と同じ 15 行に描き、編集の規則は Core の状態機械、保存は版付きの文字列にする

- 状態: 受理
- 日付: 2026-10-26
- Issue: #23
- 影響する規則: ARC-005 / ARC-008 / ARC-009 / ARC-010 / ARC-011 / FR-19 / FR-22 / FR-23 / FR-24 / FR-25 / Q14

## 文脈

施主は次の段として「設定画面」を選んだ（2026-10-26）。FR-23〜25 は、フィードの一覧と編集・表示の設定・保存の確認を求める。
これまでフィードは `Feed.defaults` の固定、表示の設定は無かった。設定は起動し直しても残す必要がある（ARC-009: 版を持つ永続化）。

## 決定

1. **開き方**: 帯の表示中に `s`。設定画面は帯と同じ 15 行に描き、閉じたら帯に戻る（FR-22）。開いている間は記事の時計を止め、取得と翻訳は裏で続ける
2. **割り付け**（Render の `SettingsRenderer`）: 見出しの行（未保存の変更があれば警告色の印）・左の FEEDS（印 `[x]`/`[ ]`・名前・ドメイン、7 行より多ければ選んでいる行が見えるように送る）と、
   その下の 3 行（入力欄か「試す」の結果）・右の DISPLAY（表示する言語・1 件の表示時間・色のテーマ・文字の雨・原文の見出し）・知らせの行・いまの状態で使えるキーの行
3. **キー**（Core の `SettingsEditor`）: FEEDS で ↑↓ 選ぶ・空白 有効／無効・`a` 足す・`e` 直す・`d` 消す（`y` で確定・ほかのキーでやめる）・`t` 試す。DISPLAY で ↑↓ 選ぶ・←→ 値を変える。
   どちらでも Tab 欄を替える・`w` 保存・Esc 閉じる。保存していない変更があれば Esc で「`w` 保存して閉じる・`x` 捨てて閉じる・Esc 戻る」を聞く（FR-25）。
   入力欄は文字を打つ（IME で確定した日本語も）・Backspace・Tab で欄を替える・Enter で決める（URL は http(s) で空白なし・名前は空でない。誤りは知らせの行に）・Esc でやめる。
   設定画面の中では `q` も文字なので、誤って押しても終わらない
4. **編集の規則は Core の純粋な状態機械**: `SettingsEditor.handle(EditorKey) -> EditorCommand`（`save`・`saveAndClose`・`close`・`test`）。端末もファイルも知らないので、キーを 1 つずつ渡してテストできる。
   端末の読み取りは Terminal の `KeyPress`（UTF-8・矢印・Tab・Enter・Backspace・単独の Esc）で、読み取りの切れ目で途中まで届いた UTF-8 の文字は次の読み取りにつなぐ
5. **保存**（ARC-009）: `$XDG_CONFIG_HOME/nene-wire/settings.txt`（無ければ `~/.config/nene-wire/settings.txt`）。1 行目が見出しと版（`nene-wire-settings 1`）、表示の項目は `キー 値` を 1 行ずつ、
   フィードは `feed on|off<TAB>名前<TAB>URL` を書いた順に。書くのも読むのも Core の `SettingsCodec` の 1 か所。読めない版・読めない行は型のある失敗（`SettingsRejection`）で返し、
   合成ルートは既定で起動して理由を知らせの行に出す（ファイルは書き換えない）。書くのは Host の `TextFile` で、一時ファイルに書いてから名前を替える
6. **反映**（FR-25: 次の記事から）: 保存したら、テーマ・1 件の時間・文字の雨・原文の見出しはすぐ次の描画から。表示の言語が変わったら訳の控えを捨てて訳し直す。
   有効なフィードの組が変わったら取得をやり直す（いま見せている記事はそのまま）。`--demo` ではフィードの変更を反映しない（保存はする）
7. **テーマ**（FR-19）: PHOSPHOR（既定）・AMBER・CYAN・MAGENTA。値はデザインのキャンバスから。どのテーマも読ませる色（本文・見出し・強調・控えめ・警告）が地と帯に対して 4.5:1 以上（テストで確かめる）
8. **試す**（FR-23）: 選んだフィードを 1 回だけ取り、件数・言語の多数決・かかった秒・OK、失敗なら理由と NG を 1 行で出す
9. **表示する言語**（FR-24）: 日本語・English・中文・한국어・Français・Deutsch・Español。翻訳の手段に入れているモデルは英語→日本語だけなので、ほかの言語に替えると「モデルが無い」と知らせて原文で流す

## 強制

- **active** → CNF-013（キーの読み取りでバイトの値に `switch` と全捕捉を書いたら落ちた。`if` で書いた）＋CNF-016／CNF-021（設定の型は private init と唯一のファクトリ）＋CNF-023（ファイルと子プロセスは Host だけ）
- テストで確かめる（`make check` の `test` 段）: 保存形式の往復・読めない版と行・CRLF と注記と既定・値の巡り・編集の規則（選ぶ・有効／無効・足す（URL と名前の誤り）・直す・消す（確かめる）・
  閉じる（未保存なら確かめる）・試す）・キーの読み取り（UTF-8 の切れ目・単独の Esc）・ファイルの読み書き（親のディレクトリを作る・一時ファイルが残らない・書けない所）・設定画面の描画・4 つのテーマのコントラスト
- 実機で確かめた（2026-10-26・Windows Terminal・120×16・`--demo`）: 一覧・有効／無効・日本語の名前でフィードを足す・試す（朝日 Headlines 40 件 · ja · 0.13 秒 OK）・テーマを AMBER にして保存すると設定画面も帯も AMBER になる・
  擬似端末で 1 バイトずつ送っても日本語の名前が保存される・消す（y）・未保存で閉じる（x で捨てる）と保存したファイルの中身

## 結果

- フィードと見た目を、アプリの中だけで変えられる。設定はファイルに残り、手で直しても読める
- 失うもの: 表示する言語は 7 つから選べるが、英語→日本語以外のモデルを入れる方法はまだ用意していない

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 設定画面だけ端末の全面を使う（デザインのキャンバスの 120×30 の案） | 施主が帯を 15 行に決めた（Q9）。開いたときに画面が跳ねる |
| 設定を JSON や TOML で書く | Foundation と `Codable` を使わない（SWF-014・CNF-015）。1 行 1 項目の文字列なら手で直せて、Core で読める |
| 読めない設定を黙って既定に戻す | ARC-009。理由を出し、ファイルは書き換えない（書き換えると利用者の手直しが消える） |
| 入力欄を Core の外（合成ルート）で扱う | 編集の規則がテストできなくなる。キーの解釈（Terminal）と規則（Core）を分けた |
| 有効の印を `●` にする | Windows Terminal で 2 桁に描かれて `]` に重なった（実機の写真）。`[x]` にした |
