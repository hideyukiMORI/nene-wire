# ADR 0014 — 記事と訳は版付きの素の文字列に保存し、起動したらそれで流し始めて、裏で条件付きで取り直す

- 状態: 受理
- 日付: 2026-10-26
- Issue: #32
- 影響する規則: ARC-009 / ARC-010 / FR-02 / FR-07 / FR-10 / FR-11 / FR-20

## 文脈

FR-11 は「取得した記事と翻訳結果を保存し、次回の起動時にすぐ表示を始められる。1 週間程度より古い記事は自動で捨てる」。
それまでは起動のたびに全部のフィードを取り直し、英語の記事を訳し直していた（100 件ほどで 20 秒）。施主は設定画面のあとに「続けて」と進めた。

## 決定

1. **置き場**: `$XDG_STATE_HOME/nene-wire/archive.txt`（無ければ `~/.local/state/nene-wire/archive.txt`）。設定（`~/.config`）とは分ける（消えても困らない状態なので）
2. **形**（Core の `ArchiveCodec` の 1 か所・ARC-009）: 1 行目 `nene-wire-archive 1`。`feed`（URL・ETag・Last-Modified）・`article`（フィードの URL・識別子・公開の秒・見出し・出だし・リンク・フィード名）・
   `translation`（表示の言語・識別子・見出し・出だし）を 1 行ずつ、欄はタブ区切り。欄の中の `\`・タブ・改行は書き換え、無い欄は空・ある欄は `=` を頭に付ける。
   読めない版・行は型のある失敗（`ArchiveRejection`）で返し、合成ルートは空で始めて理由を知らせの行に出す（次に保存するときに書き直す。設定と違い、利用者が手で直すものではない）
3. **残すもの**: フィードごとの最後に取れた記事・条件付きの取得の手がかり・いまの表示の言語の訳の控え。公開から **7 日**より古い記事（公開時刻の無い記事は残す）と、その訳は、読み込むときと保存するときに捨てる
4. **起動**: 保存した記事で巡りを始め（`Rotation.restore`）、訳の控えを読み戻し（訳し直さない）、まだ訳していない記事を待たせる。
   取得の予定は保存した手がかりで再開し（`FetchSchedule.resuming`）、どのフィードもすぐに条件付きで取りに行く（更新が無ければ 304）。
   保存した記事を読み戻したフィードの最初の取得は、速報にしない（前に流していたときから増えた記事を、まとめて速報にしない）
5. **接続シーケンス**: 保存した記事があれば「保存した記事を読み込み … N 件」の行を打ち終えたところで終える（取得を待たない）。最短の 2.5 秒は残す
6. **保存の時**（`ArchiveKeeper`）: 記事が取れたか訳が届いたら印を付け、30 秒に 1 回まで保存する。終わるときは必ず保存する（`q`・Ctrl+C・SIGTERM。異常終了では保存しない）
7. **`--demo`** は読み込まず、保存もしない（架空の記事を残さない）

## 強制

- **active** → CNF-015（`Codable` の禁止。保存の形は手で書く）＋CNF-013（文字での分岐に全捕捉を書いて落ちたので `if` にした）
- テストで確かめる（`make check` の `test` 段）: タブ・改行・`\` を含む見出しの往復・読めない版と行（記事の前にフィードが無い・公開の秒が数でない）・7 日より古い記事とその訳を捨てる・
  保存した手がかりで再開してすぐ取りに行く・読み戻した記事が速報にならない・読み戻した訳は訳し直さない
- 実機で確かめた（2026-10-26・本物のフィード・擬似端末）: 1 回目に 87 件と訳 80 件を保存 → 2 回目は「保存した記事を読み込み … 87 件」から流れ始め、NHK と The Guardian World は「更新なし」（304）、
  訳し直しは 0 件。接続シーケンスは最短の 2.5 秒で終わり、取得を待たない

## 結果

- 起動し直しても前の記事と訳ですぐ流れ、ネットにも翻訳にも余計な仕事をさせない
- 失うもの: 75 KB ほどのファイル。表示の言語を替えると、ほかの言語の訳の控えは保存しない

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 記事が届くたびにすぐ保存する | 1 回の起動で数十回書く。30 秒に 1 回で足りる |
| 設定と同じファイルに入れる | 設定は利用者が手で直すもの、保存は消えても取り直せるもの。性質が違う |
| 読めない保存を黙って捨てる | ARC-009。理由を知らせの行に出す |
| 保存した記事のフィードも取得を待ってから流す | FR-11 の「すぐ表示を始められる」に合わない |
