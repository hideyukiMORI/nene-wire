# ADR 0013 — 翻訳のオン／オフは設定の 1 項目にし、設定画面と帯の表示中の t の両方から切り替える

- 状態: 受理
- 日付: 2026-10-26
- Issue: #27
- 影響する規則: ARC-009 / FR-10 / FR-22 / FR-24 / Q16

## 文脈

施主は「テーマの変更や翻訳モードのトグルってどうやったっけ」と聞き、翻訳のオン／オフの切り替えが無いと分かると「足して」と決めた（REQUIREMENTS の Q16）。
FR-24 の表示の設定には翻訳しないという項目が無く、それまでは翻訳の手段が入っていれば必ず訳していた。

## 決定

1. **設定の 1 項目**: 表示の設定に「翻訳: する／しない」（`DisplaySwitches.translate`・既定はする）。設定画面の DISPLAY で「表示する言語」の次の行
2. **帯の表示中の `t`**: 同じ項目を裏返して、その場で設定のファイルに保存する。いま見せている記事もすぐ出し直す（原文⇄訳）。知らせの行に「翻訳をオフにした（原文で流す）  t で切り替え」
3. **翻訳しない間**: 原文のまま出し、「未翻訳」の印も出さない。新しく訳しに行かない（走っている分は受け取って控える）。状態の行は `TRANS オフ`
4. **状態の行のキー**に `t 翻訳` と `s 設定` を足した（設定画面の開き方が画面に出ていなかった）
5. **保存形式**: `translate on|off` の行を足した。版は 1 のまま: この行が無いファイル（v0.3.0 より前）は「する」として読む。
   逆に、この行のあるファイルを v0.2.0 以前は読めないが、v0.2.0 以前には設定のファイルが無い（設定画面は v0.3.0 から）

## 強制

- テストで確かめる（`make check` の `test` 段）: 裏返しの往復・`translate` の無いファイルは「する」・読めない値は拒む・設定画面の行・`t` のキー・状態の行の `TRANS オフ` と `t 翻訳`
- 擬似端末で確かめた（2026-10-26・`--demo`・翻訳の手段あり）: 英語の記事が訳で出ている間に `t` → すぐ原文になり `TRANS オフ`・もう一度 `t` → 訳に戻る・設定のファイルに `translate off`

## 結果

- 原文で読みたいときに 1 キーで切り替えられ、次に起動しても覚えている
- 失うもの: 状態の行のキーの案内が長くなった。狭い端末で右端が切れたので、#34 で収まらなければ優先度の低いもの（FEED・NET・取得失敗・TRANS・←→・SPC・t）から落とし、何件目か・速報・停止中・`s 設定`・`q 終了` は必ず残すようにした（`LineFit`）

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| `t` はその場だけ切り替え、保存しない | 設定画面の項目と食い違う。切り替えたら覚えているほうが分かりやすい |
| 版を 2 に上げる | 足した行が無くても読めるので、読めなくなる組み合わせが無い |
